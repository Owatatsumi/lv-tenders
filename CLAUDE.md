# Project: LV-Tenders (Агрегатор госзакупок Латвии)

## Бизнес-логика
B2B SaaS-платформа для малого бизнеса в Латвии.
Система собирает открытые данные о тендерах с `data.gov.lv` и `eis.gov.lv`, извлекает текст из документации, делает краткую AI-выжимку на 3 пункта (суть, бюджет/сроки, требования к участнику) и отправляет уведомления клиентам по их ключевым словам.

## Технический стек
- **Frontend & API:** Next.js (App Router), TypeScript, Tailwind CSS, shadcn/ui.
- **Database:** Supabase (PostgreSQL). Обязательно использовать RLS (Row Level Security) при создании таблиц.
- **Scraper:** Node.js + Playwright для парсинга порталов.
- **Payments:** Stripe Checkout для подписок.

## Правила для агента (Claude Code)
1. Перед написанием компонентов используй MCP `context7` для проверки свежей документации Next.js и Stripe.
2. Для изучения структуры и селекторов сайтов data.gov.lv и eis.gov.lv используй MCP `playwright`.
3. Всегда запускай линтер и проверяй типизацию TypeScript перед git commit.
4. Создавай интерфейс с заделом на мультиязычность (LV / RU). Основной язык парсинга данных — латышский.
